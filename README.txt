BHCRMS - Barangay Ibaba Health Center

HOW TO RUN:
1. Open this folder in VS Code.
2. Open index.html in a browser.
3. Login:
   Admin: admin / admin123
   Health Worker: worker / worker123

DESIGN:
Edit css/style.css. This controls colors, cards, sidebar, buttons, tables, spacing and responsive layout.

PATIENT RECORDS:
Click a patient's name to open the patient profile.
The profile shows basic information, consultation history, and reports.
Use + Add Consultation or + Add Report to create records.

DATA:
This demo uses browser LocalStorage. It is suitable for a school prototype/demo, not a production medical records system.

REPORTING:
Dashboard now reports consultations by category: Pregnant Women, Babies/Children, Senior Citizens, and General Patients. It shows total consultations, unique patients consulted, registered patients, consultation rate, and has a Print Report button.

RATINGS: The ratings feature and ratings page have been removed from the interface.
